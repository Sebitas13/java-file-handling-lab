# Security Policy

## Supported versions

This is a small educational project. Security fixes are applied to the latest
version on `main`.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private vulnerability reporting:

1. Open the repository on GitHub.
2. Go to **Security** → **Advisories**.
3. Click **Report a vulnerability**.

Include:

- a short description and impact;
- steps to reproduce, with fictional data;
- affected version or commit;
- any suggested fix.

This project is not intended for real personal data. If you adapt it, do not
store real names, IDs, phone numbers or dates without encryption and access
controls. Do not include real names, credentials, tokens or production data in
a report.
