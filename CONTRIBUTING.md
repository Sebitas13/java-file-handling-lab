# Contributing

Thanks for taking a look at this project.

## Setup

1. Install JDK 21 and Maven.
2. Clone the repository.
3. Run `mvn test` to verify the setup.

## Before opening a pull request

- Keep the change focused.
- Add or update tests when behavior changes.
- Run `mvn test`.
- Do not commit real personal data, credentials or generated files from `data/`.
- Update the README if the user-facing behavior changes.

## Style

- Java 21.
- Four spaces, UTF-8, no wildcard imports.
- Prefer clear names and small methods.
- Keep the console messages in Spanish; code identifiers can stay in English or Spanish as appropriate.

## Security

Read [SECURITY.md](SECURITY.md). Do not report vulnerabilities in public issues.
